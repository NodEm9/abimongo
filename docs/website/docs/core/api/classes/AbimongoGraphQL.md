AbimongoGraphQL class provides a way to create a GraphQL schema
with custom type definitions and resolvers, while integrating
with Redis for real-time subscriptions and caching.
It supports multi-tenancy and role-based access control (RBAC).

## Param

## Explanation

The `AbimongoGraphQL` class is designed to facilitate the creation of a GraphQL API
that integrates seamlessly with MongoDB and Redis. By leveraging Redis for
subscriptions, it enables real-time data updates to clients, making it suitable
for applications that require live data feeds as well as robust multi-tenant support.
The built-in role-based access control (RBAC) ensures that data access is 
properly managed based on user roles, enhancing security and compliance.
The class allows for easy customization of the GraphQL schema through 
custom type definitions and resolvers, providing flexibility to adapt 
to various application requirements.
Testing and extending the `AbimongoGraphQL` class is straightforward due to its modular design. 
Its clear separation of concerns between schema definition,
resolver logic, and Redis integration allows developers to focus on specific aspects
without affecting the overall functionality. This modularity also facilitates
unit testing, as individual components can be tested in isolation.
Try it in [playground](https://studio.apollographql.com/sandbox/explorer/?) now!

// Create Abimongo instance with default config
// This time we will add custom typeDefs and resolvers.
const abimongo = await AbimongoBootstrapFactory.create();
// Get GraphQL instance
const graphql = await abimongo.getGraphQL();
// Add custom typeDefs
graphql.customTypeDefs(`
 type CustomType {
  id: ID!
  name: String!
 }
`);
// Add custom resolvers
graphql.customResolvers({
  Query: {
   customType: () => {
    return { id: '1', name: 'Custom Name' };
   },
  },
});
// Generate the final schema
const schema = await graphql.generateSchema();

## Remarks

***Autogenerated schema vs Custom schema***
 The `AbimongoGraphQL` class provides flexibility in schema generation.
 If you want to automatically generate builtin GraphQL schema for example,
 most organisation prefer to create well defined and organised schema structure,
 which is a common practice. Abimongo also takes care of such scenario by providing 
 custom methods to the `AbimongoGraphQL` class.
 These methods allow you create custom type definitions and resolvers as 
 needed by accessing these methods:
 `AbimongoBootstrap.customResolvers()` or `AbimongoBootstrap.customTypeDefs()`.
 Notices that in the above example, we created an Abimongo instance with 
 AbimongoBootstrapFactory and that works only when you have use the Abimongo bootstrap CLI 
 to bootstrap your application. That's when you can take advantage of the `AbimongoBootstrapFactory` class 
 which generates a fully configured Abimongo instance for you in an abimongo.config file. 
 You can then use that instance to get the GraphQL instance and add your custom typeDefs
 and resolvers before generating the final schema.
