# Contributing Guidelines

Thank you for your interest in contributing to this project! Please follow these guidelines to help us maintain a high-quality codebase.

## How to Contribute

1. **Fork the repository** and create your branch from `main`.
2. **Write clear, concise commit messages**.
3. **Add tests** for any new features or bug fixes.
4. **Run all tests** before submitting a pull request.
5. **Document your code** and update any relevant documentation.

## Pull Request Process

- Ensure your branch is up to date with `main`.
- Submit a pull request with a clear description of your changes.
- Reference any related issues in your PR description.
- One of the maintainers will review your PR and provide feedback.

## Code Style

- Follow the existing code style and conventions.
- Use descriptive variable and function names.
- Keep functions small and focused.

## Reporting Issues

- Use the issue tracker to report bugs or request features.
- Provide as much detail as possible, including steps to reproduce.

## Code of Conduct

- Be respectful and considerate in all interactions.
- See [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md) for details.
