getTenantDB

@abimongo/core v1.0.0

@abimongo/core / getTenantDB

Function: getTenantDB()

getTenantDB(tenantId): Promise<Db>

Defined in: packages/core/src/utils/builders/getTenantDb.ts:15

Retrieves the database instance for a specific tenant. If the database is already cached, it returns the cached instance. Otherwise, it uses abimongo to get the database for the tenant and caches it.

Parameters​

tenantId​

string

The ID of the tenant whose database is to be retrieved.

Returns​

Promise<Db>

A promise that resolves to the MongoDB database instance for the tenant.

Throws​

If the database for the specified tenant is not found.
